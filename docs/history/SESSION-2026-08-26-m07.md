# Session 2026-08-26 — m07: prosody-preserving dubbing (Tier 0 + Tier 1)

**Milestone:** m07-prosody — restore the source speech's *delivery* (pauses,
stress, pacing) that a plain translate-and-resynthesize pipeline flattens away.
Implements the decisions locked in `docs/plans/prosody-preserving-dubbing.md`
**(on-by-default, per-piece synthesis)**.

## Problem
The pipeline did `speech → bare text → translated bare text → cold TTS`,
losing where to pause, which words to stress, and how fast/slow to speak.

## What changed

### New: `backend/services/prosody.py`
Pure offline math (librosa-free; just numpy) — no model downloads:
- `word_stats(audio, sr, words)` — per-word RMS energy + duration from aligned
  timestamps.
- `compute_pace(words, duration)` → `pace_multiplier` (clip 0.8–1.4).
- `annotate(text, stats)` → director's-script `instruct` (stress/emphasis +
  pause directives) and uppercased `marked_text`.
- `rate_hint(pace)` and `split_by_breaks(segments)` helpers.

### Pipeline wiring (`backend/services/dubbing.py`)
- `_measure_prosody(db, project_id, master_wav)` — loads the master 16k WAV
  once, splits each segment's source text into evenly-spaced words, measures
  real energy/prosody, stores `source_wps`, `pace_multiplier` and
  `prosody_annotation` (the director's-script instruct).
- `_synthesize_segment` now passes `instruct=prosody_annotation` into
  `generate_audio_sync`.
- **Per-piece synthesis:** `_split_into_pieces()` splits translated text at
  punctuation bounds; each piece is synthesized separately and concatenated
  with a small cross-piece pause. This lays pauses down deterministically
  regardless of whether the TTS obeys markers (the design's recommended
  fallback). Short lines fall back to a single render.
- `prosody_preserve` flag (default **ON**) on `DubbingProject`; a UI checkbox
  to turn it off for comparison.

### DB / models
- `dubbing_projects.prosody_preserve` (BOOLEAN default TRUE),
- `dubbing_segments.prosody_annotation` (TEXT) + `source_wps` (FLOAT),
- migration additions.

### UI (`DubbingTab.tsx` / `client.ts`)
- "Preserve delivery (pauses, stress & pacing)" checkbox on the create form
  (default on), threaded to the backend.

### Tests
- `backend/tests/test_prosody.py` (6) — real-audio word_stats, pace, annotate
  (stress+pause), split_by_breaks, split_into_pieces.
- `backend/tests/test_dubbing_pipeline_simulation.py` — new test asserting the
  pipeline (prosody on) measures `source_wps` and sets `prosody_annotation`,
  still reaching `ready`.
