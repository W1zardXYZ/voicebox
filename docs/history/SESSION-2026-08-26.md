# SESSION-2026-08-26 — m01-backends (Parakeet V3 · Diarization · Dictionary · Translation)

**Branch:** `m01-backends`

**Test machine:** off-site MacBook (nothing downloaded/run on the authoring machine, per plan)

## What landed

### 1. Parakeet V3 STT (`backend/backends/parakeet_backend.py`)
- New `ParakeetBackend` implementing the `STTBackend` protocol (NeMo `ASRModel.from_pretrained` on `nvidia/parakeet-tdt-0.6b-v3`).
- `transcribe()` (plain text) + `transcribe_segments()` (word timestamps).
- Lazy load, `_is_model_cached`, `model_load_progress`, unload — same contract as the Whisper backends.
- Device: CUDA/CPU via `get_torch_device(force_cpu_on_mac=True)` (no Metal path yet).

### 2. Speaker diarization (`backend/backends/diarization_backend.py`)
- New `DiarizationBackend` protocol in `backends/__init__.py`.
- `PyannoteDiarizationBackend` using `pyannote/speaker-diarization-3.1` (gated — requires `HF_TOKEN`; raises a clear error if absent).
- `POST /diarize` route (`routes/diarization.py`) returning `{speaker_id, start, end}` turns.
- `services/diarization.py` includes `merge_speakers_into_segments()` — overlap-based speaker assignment onto word/segment timestamps (pure function, unit tested).

### 3. Register/route wiring (`backends/__init__.py`)
- New engine registries: `STT_ENGINES` (whisper + parakeet), `DIARIZATION_ENGINES`, `TRANSLATION_ENGINES`.
- `ModelConfig` gained `word_timestamps: bool` flag.
- `get_stt_backend_for_engine()`, `get_diarization_backend()`, `get_translation_backend()` factories.
- `get_all_model_configs()` / `get_stt_model_configs()` / `get_diarization_model_configs()` include the new engines → they appear in `ModelManagement` UI automatically.
- `unload_model_by_config`, `check_model_loaded`, `get_model_load_func` gained parakeet + pyannote branches.
- `POST /transcribe` accepts `engine=whisper|parakeet`; new `POST /transcribe/segments` returns word-level timestamps (defaults to Parakeet).

### 4. Pronunciation dictionary
- New SQLAlchemy table `pronunciation_dictionary` (`database/models.py`).
- `GET/POST/DELETE /dictionary` (`routes/dictionary.py`) — upsert by word, list w/ language filter, delete by id or word.
- `services/dictionary.py` CRUD + `apply_dictionary(text, language)` hook that wraps dictionary words in `<phoneme alphabet="ipa">…</phoneme>` for TTS engines that honor inline phonemes.

### 5. Translation
- `TranslationBackend` protocol + `LLMTranslationBackend` (`backends/translation_backend.py`) — reuses the existing local LLM backend (Qwen3) — no new model download; OpenRouter BYOK plugs in via the same seam.
- `POST /translate` (`routes/translation.py`) with `max_chars/min_chars` length-fit.
- `services/translation.py` wrapper.

### 6. Dependencies
- `backend/requirements-studio.txt` — optional extras (`nemo-toolkit[asr]`, `pyannote.audio`, `speechbrain`, `torchaudio`), deliberately NOT in the base install.
