**Branch:** `m04-model-reuse`

## Problem
The off-site MacBook already has Voicebox installed with ~20 GB of models cached at
`/Users/w1zard/.cache/huggingface/hub`. Re-downloading TTS/STT/LLM weights for the
fork's dubbing pipeline would be wasteful.

## What landed
- **Dubbing TTS no longer defaults to Kokoro** — `_synthesize_segment` now resolves
  the engine from the selected voice profile via `_resolve_profile_voice()`:
  1. preset engine (user-explicit), 2. `default_engine`, 3. **`qwen` + `1.7B`**
  (the already-cached MLX Qwen3-TTS). This removes the only hardcoded engine that
  would have triggered a fresh ~350 MB Kokoro download (and instead reuses the big
  cached Qwen TTS).
- **Engine resolution unit-tested** (cloned profile → qwen/1.7B; kokoro preset → kokoro;
  missing → qwen/1.7B).
- **Docs**: `docs/plans/model-reuse.md` (spec) + `docs/MODEL_REUSE_SETUP.md` (HOWTO)
  + README section for cache reuse.
- The rest of the pipeline already reuses cached models:
  - Whisper STT branch loads `turbo` → cached `whisper-large-v3-turbo`.
  - Translation uses the cached Qwen3 LLM (0.6B/4B 4-bit).
  - TTS uses cached Qwen3-TTS / CustomVoice / Chatterbox via profile selection.
