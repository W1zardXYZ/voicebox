## What landed

### Real alignment + time-stretch in the assembler (`backend/services/dubbing.py`)
`_assemble_track` now honors the full DUBBERc-style placement semantics:
- **`alignment` (start | center | end)** — the synthesized audio is placed at the
  beginning, middle, or end of its original segment window.
- **`pace_multiplier`** — scales the effective target duration (faster/slower read).
- **`auto_stretch`** — pitch-preserving phase-vocoder stretch via
  `librosa.effects.time_stretch` to fit the target window exactly (with a linear
  resample fallback if librosa is unavailable).
- Alignment math extracted to the pure `_alignment_start_sample()` helper (unit-tested).

### Video export (`POST /dubbing/projects/{id}/export` + `GET /dubbing/video/{id}`)
- `export_video()` muxes the dubbed master WAV back onto the original media with
  ffmpeg (`-c:v copy -c:a aac -shortest`) → `dubbed_video.mp4`, stored on the project.
- Clear error if ffmpeg is missing (`brew install ffmpeg`) or the project isn't ready.
- New `dubbed_video_path` column on `dubbing_projects`, surfaced in the API + frontend.

### Frontend
- Project panel gains an **Export video** button + inline video player for the
  exported MP4. `apiClient.exportDubbedVideo` / `dubbedVideoUrl` added.
