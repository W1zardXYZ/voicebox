# Session 2026-08-26 — m05: Parakeet STT across the app

**Milestone:** m05-stt-anywhere — surface the Parakeet V3 STT engine across
Captures/dictation and voice-profile transcription.

## What changed

### Backend
- **`captures.stt_engine` + `capture_settings.stt_engine` columns** (default `whisper`)
  — `backend/database/models.py` + `_migrate_captures()` in
  `backend/database/migrations.py` (idempotent `_add_column` backfill).
- **Engine dispatch in `create_capture` / `retranscribe_capture`** —
  `backend/services/captures.py` now routes to `get_parakeet_model()` vs
  `get_whisper_model()` based on `stt_engine`, persists the resolved
  `stt_engine`/`stt_model`, and falls back to `whisper` for invalid values.
- **Request/response plumbing** — `stt_engine` on `CaptureResponse`,
  `CaptureSettingsResponse/Update`, and `CaptureRetranscribeRequest` in
  `backend/models.py`; `engine` Form/request field on the captures create and
  retranscribe endpoints in `backend/routes/captures.py`.
- **Critical `routes/dubbing.py` fix** — removed the module-level
  `from ..database.session import SessionLocal` (the `None`-at-import footgun)
  in favor of `db_session.SessionLocal()` resolved at call time (lines 82, 110).
  This unblocks `POST /dubbing/projects` 500.

### Frontend
- **STT engine dropdown** in Settings → Captures → Transcription
  (`ServerTab/CapturesPage.tsx`) — choose **Whisper** or **Parakeet V3**; the
  Whisper model-size row is hidden when Parakeet is selected.
- **API plumbing** — `engine` threaded through `ApiClient.transcribeAudio`,
  `useTranscription`, and the capture settings cache-optimistic update.
- **Voice-profile transcription honors the engine** — `SampleUpload` and
  `ProfileForm` pass the selected `stt_engine` to `/transcribe`.
- English i18n keys for the engine selector.

### Test
- **New `backend/tests/test_captures_engine_dispatch.py`** — 3 tests verifying
  parakeet dispatch, whisper default, and invalid-engine fallback (real SQLite;
  backends/audio-decode mocked, no downloads).

## SessionLocal gotcha recap
`SessionLocal` imported at module load is `None` unless the app has initialized
the session factory first. Always call `db_session.SessionLocal()` at call time —
fixed for dictionary, dubbing service, and now `routes/dubbing.py`.
